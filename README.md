# imagination_machines
This repo contains the code corresponding to the experiments in "Paper 3: Linear Encoding of Koopman Spectra in Predictive Agents" of the Imagination Machines series.
It demonstrates that, with the right data transformation, the Koopman spectral structure of any data sequence can be encoded in a distributed manner within the weights of a simple recurrent neural network using next-step prediction error alone.
The source material is available here: https://philpapers.org/rec/TRAIMA-2
